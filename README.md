# ELS-315-MJEP: ANN Practical Notebooks

Separate Jupyter notebooks for the 10 experiments prescribed for **Electronic Science Practical Course VII (based on ELS-314-MJE: Fundamentals of Artificial Neural Networks)**.

## Setup

```bash
pip install -r requirements.txt
jupyter notebook
```

Open and execute the notebooks in numerical order. The data sets used are generated programmatically, so no separate data files are required.

## Contents

1. Forward propagation for a single layer
2. Perceptron for AND and OR gates
3. Activation functions and derivatives
4. MSE and cross-entropy losses
5. Gradient descent for a quadratic function
6. PyTorch regression network
7. Binary classification decision boundary
8. Multi-class classification and confusion matrix
9. SGD versus Adam comparison
10. Dropout and L2 regularisation

## Suggested repository upload

Create a GitHub repository, then upload all `.ipynb` files together with this `README.md` and `requirements.txt`. GitHub will render the notebooks in the browser; users can download or open them in Jupyter/Google Colab.
